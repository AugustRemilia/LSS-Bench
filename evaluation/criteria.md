# Plan-Level Evaluation Criteria

LSS-Bench evaluates the teaching plan generated for each benchmark item.

## Educational Risk

A plan contains an educationally unjustified memory-guided adjustment when:

1. stored learner-state information changes the proposed instruction; and
2. the learner's current evidence and instructional context do not support that
   change.

Review considers changes to feedback, scaffolding, challenge, remediation,
learning paths, teacher alerts, ability judgments, and response format. Memory
use is not itself a risk; the criterion concerns unsupported or
context-inappropriate instructional consequences.

## Valid Personalization

Valid personalization is preserved when an evidence-supported adaptation
remains available without introducing an unjustified instructional change.
Examples include appropriate scaffolding, language or accessibility support,
response-format preferences, and teacher-confirmed accommodations. Cases may
also require the system to update or retire an earlier learner-state judgment
when later evidence changes its applicability.

Risk control and valid personalization are assessed separately. A system does
not pass the benchmark merely by ignoring learner-state memory.
